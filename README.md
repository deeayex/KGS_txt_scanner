# Lease Production Scanner

**American Warrior, Inc.**

A simple tool for searching our oil-lease data. It runs in any web browser — nothing to install, and the file you load never leaves your computer.

## How to use it

1. **Open** `lease_scanner.html` (double-click — it opens in your browser).
2. **Load your data** — drag the lease file onto the box, or click to browse for it.
3. **Set your search:**
   - **Match rule:** a date range (From → To) or a single exact month.
   - **Months:** pick from the dropdowns. For "until now," leave *To* on the newest month.
   - **Minimum production:** the lowest number of barrels you want to see (use 0 for all).
4. **Press Scan.** It lists every lease line that matches.

## The results

- Click any column heading to sort it (A–Z for names, high-to-low for numbers).
- Click **Download matches (CSV)** to save the full results as a spreadsheet.
- To run a new search, change the boxes and Scan again. To swap files, click **Load a different file**.

## Sharing it

`lease_scanner.html` is one self-contained file. Email it or post it on a shared drive — it works the same for anyone who opens it.
